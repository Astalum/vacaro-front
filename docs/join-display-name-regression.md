# 参加時の表示名の修正（2026-11-08）

招待フォームの送信時に`PATCH /me`でプロフィールを書き換えていた処理を削除した。入力された別名は`POST /invitations/:token/participants`の`display_name`へ渡し、イベント内の参加者名として保存する。既存アカウント名はフォームの初期値として利用する。

入力欄は「イベントでの表示名」とし、オートコンプリートの用途を`nickname`にした。未ログインの場合は従来どおり入力名でゲストセッションを作成する。
